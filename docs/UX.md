# UX 설계: 사용자 · 핵심 과업 · 흐름

겉모양보다 먼저 "누가, 언제, 무엇을 하려고 여는가"를 정하고 화면을 그 순서로 배치한다.

## 1. 사용자와 상황

| 사용자 | 언제 여나 | 기기 | 머무는 시간 |
|---|---|---|---|
| 학생 | 야자 가기 직전(자리 있나?), 쉬는 시간(얼마나 했나?), 답변 알림 | 휴대폰 | 10~30초 |
| 감독 선생님 | 야자 시작 직후(누가 안 왔나?), 순회 중, 다음 날 아침(문의 처리) | PC · 태블릿 | 1~5분 |
| 키오스크 이용 학생 | 입실 · 퇴실 순간 | 태블릿(서서) | 5초 이내가 목표 |

## 2. 핵심 과업 (우선순위 순)

### 학생
1. **지금 자리가 있는지** 확인한다 → 홈 상단 배너와 빈 자율석 타일, 좌석 탭
2. **오늘·이번 주 얼마나 했는지** 본다 → 홈 오늘 카드, 기록 화면
3. **선생님 답변이 왔는지** 본다 → 문의 탭 배지(안 읽은 답변 수)
4. 문의 · 분실 신고를 남긴다 → 문의 탭 하단 버튼 → 하단 시트

### 감독 선생님
1. **오늘 안 온 지정석 학생**을 바로 안다 → 대시보드 "아직 안 온 학생" 카드
2. 지금 누가 어디 앉아 있는지 → 입실 중 목록 · 좌석 화면
3. **문의에 답한다** → 목록에서 바로 답장(모달 없이 펼쳐서 입력)
4. 퇴출 후보 · 블랙리스트 · 좌석 배치 관리 (가끔)

### 키오스크
1. 얼굴을 비춘다 → 확인 → 지정석이면 바로 입실 / 자율석이면 자리 하나 탭
2. 실패하면 **이유와 다음 행동**을 바로 안다 (다시 시도 · 선생님 호출)

## 3. 설계 원칙
- **한 화면 한 목적**: 화면 제목만 보고 무엇을 하는 곳인지 알 수 있게
- **상태는 배너 한 줄**: 문장형 큰 제목 대신 상단 배너로 짧게
- **행동은 엄지 닿는 곳**: 주요 버튼은 화면 하단, 터치 영역 44px 이상
- **빈 상태도 안내**: 데이터가 없으면 다음에 할 일을 알려준다
- **오류는 원인 + 해결책**: "실패" 대신 "얼굴이 너무 멀어요 → 한 걸음 다가와 주세요"
- **강조색은 하나(파랑)**: 아이콘·배지는 무채색, 파랑은 "지금 할 일"에만
- **개인정보**: 좌석 상세에 다른 학생 이름을 노출하지 않음

## 4. 이번에 반영한 흐름 개선
- 학생: 좌석을 누르면 상세 시트(상태 · 사용 시작 시각), 문의 탭에 안 읽은 답변 배지, 글쓰기 실시간 글자 수 · 입력 오류 안내
- 관리자: 대시보드 "아직 안 온 학생"(지정석 기준) 카드, 문의 목록에서 바로 답장 · 상태 필터
- 키오스크: 연속 실패 시 원인별 안내와 "선생님께 도움 요청" 안내, 인식 단계 표시
